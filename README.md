# iPAS AI 應用規劃師 ─ 智慧練習系統 (初級 555 題旗艦版)

> 專為經濟部產業人才能力鑑定（iPAS）「**初級 AI 應用規劃師**」打造的現代化高效率練習平台。包含 114 年至 115 年全梯次官方真題、秒選速查、架構精析、到訪人次統計與雙軌留言回饋功能。

🔗 **線上體驗入口 (GitHub Pages)**：[https://mosful.github.io/iPAS/](https://mosful.github.io/iPAS/)

---

## 🎯 系統亮點與核心特色

1. **555 題全覆蓋題庫（官方公告真題 450 題 + 模擬/樣題 105 題）**：
   - 🟣 **115 年第三次初級試題**：第一科（50題）＋ 第二科（50題）
   - 🟢 **115 年第二次初級試題**：第一科（50題）＋ 第二科（50題）
   - 🟡 **115 年第一次初級試題**：第一科（50題）＋ 第二科（50題）＋ 第二科官方公告題（50題）
   - 🔵 **114 年第四梯次初級試題**：第一科（50題）＋ 第二科（50題）
   - 📝 **樣題與模擬練習題庫**：精選 105 題
   - 支援「全真題大會考」、「單梯次衝刺」、「分科專項」與「錯題複習」多元模式。

2. **考前極速衝刺與深度考點精析**：
   - 專屬考點章節：115-3、115-2、115-1、114Q4 全題型分佈與核心考點解析。
   - ⚡ **秒選速查表**：最常考關鍵破題組（ReAct、多雲架構、Re-ranking、同態加密、資料漂移等）。
   - 🔬 **訓練流程×架構深解**：對比 MLOps、MCP、RAG、Fine-tuning 等架構差異。

3. **雙軌考生交流與意見回饋系統**：
   - **方式一：免登入快速寄信**：支援雲端試算表自動留存通知，並可直接呼叫本機郵件軟體（`mailto:`）一鍵發送疑義回饋。
   - **方式二：登入 GitHub Discussions (Giscus)**：以 GitHub 帳號公開留言討論，支援 Markdown 與表情符號互動。
   - **常駐懸浮反饋按鈕 (FAB)**：測驗中發現題目疑問，隨時點擊一鍵反饋並自動帶入題號資訊。

4. **不蒜子 (Busuanzi) 到訪與瀏覽量統計**：
   - 側邊欄與首頁底部即時呈現全站訪客人次（UV）與總瀏覽量（PV）。

5. **極致響應式深色極客設計**：
   - 純原生 HTML5、CSS3、JavaScript 開發，零相依套件、極速載入，相容手機、平板與桌上型電腦。

## 🚀 部署說明

本專案採用 **GitHub Pages** 搭配 **GitHub Actions** 自動化 CI/CD：
- 只要推送（`git push`）程式碼至 `main` 分支，`.github/workflows/deploy.yml` 將自動觸發建置與部署作業。
- 專案首頁自動發布於：`https://mosful.github.io/iPAS/`
